# KMB LMS Module Kit

Panduan sembilan modul Microsoft Teams untuk guru Kolej MARA Banting.
Disediakan oleh Unit Digitalisasi Pengajaran dan Pembelajaran, KMB.

Laman: https://kmb-digital.github.io/kmb-lms-module-kit/

## Kandungan
- `index.html` — keseluruhan aplikasi (HTML, CSS dan JavaScript dalam satu fail)
- `og-image.png` — gambar pratonton untuk pautan WhatsApp
- `favicon.svg` — ikon tab pelayar

## Nota
Kemajuan guru disimpan dalam pelayar masing-masing sahaja (localStorage); tiada data dihantar ke mana-mana pelayan.
Ilustrasi paparan dilukis untuk kit ini dan bukan tangkapan skrin sebenar.
Microsoft Teams ialah tanda dagangan Microsoft Corporation. Kit ini tidak dihasilkan atau disahkan oleh Microsoft.
